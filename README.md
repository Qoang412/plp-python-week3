\# Week 3 Assignment: Conditions and Loops



\## Project Files



\- `grade\_reporter.py`: Uses a for loop and conditional statements to assign grades, count passes and failures, and calculate the average score.

\- `bug\_hunt.py`: Demonstrates debugging a while loop by identifying and fixing three programming errors.



\## Bug Hunt Reflection



The hardest bug to find was the incorrect while loop condition because it did not produce an error message. The program ran successfully but calculated the wrong answer. I knew something was wrong because the expected sum was 15, while the program initially produced a different result. Changing the loop condition allowed it to include all five numbers.
